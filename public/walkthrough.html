NSE Copilot

A market model that tells you when it doesn't know

Every other stock tool always has an answer. This one abstains — and backs the refusal with numbers it measured on itself.

Who it is for

One person, one decision.

A salaried investor holding ₹2–5 lakh across 6–8 NSE large-caps, checking in weekly, asking one question: is today a day to act, or a day to wait?

not intraday not a tip service no execution not advice no price targets

MODEL_CARD.md §1 — naming the limits is what makes the remaining claim usable.

What it learns from

49,759 sessions of NSE large-caps.

Scale-free on purpose: a model given raw closes learns the ticker, not the market.

Why the earlier version reported 58%

I reproduced my own leak to find out which part was lying.

Honest — date split, no raw prices55.03%@0.70 → 63.46%
+ raw prices and 30 close lags54.64%@0.70 → 61.39%
+ a row-wise random split64.23%@0.70 → 82.78%

The random split was worth +9.2 points on its own. The raw price features that everyone blames were worth nothing — they made it slightly worse.

ml/experiments/why_58.py reruns all three. The README originally blamed the price features; that was wrong, and it has been corrected.

What it does with a coin flip

It refuses — and the API omits the field entirely.

abstains · 89.8% of sessions

frozen gate · 0.60
5,729 holdout sessions, ordered by confidence →
coverage 10.2% accuracy on calls 55.50% today: 0 of 17 called on direction

Below the gate the response has no direction key, so a client cannot render a call it was never given. A Python test, the rules layer and a browser test each enforce that independently. A board of refusals is the product working.

The edge lives almost entirely in stressed volatility. In the normal tercile the model is below a coin flip — and the dashboard renders that in red rather than hiding it in an average.

Same on individual names: four of seventeen are below 50% on their own holdout slice, and each card says so.

What it is made of

Two frozen models, twelve tools, one rule.

Direction
Pooled LightGBM + isotonic calibration, purged walk-forward, 58 features
Magnitude
A second frozen model on whether the move exceeds recent normal
Agent
Gemini 2.5 Flash, 12 tools — every number it says comes from a tool call
Rules
Independently blocks a directional claim with no model call behind it
Sentiment
FinBERT on headlines, ported from the earlier project
App
Next.js 16 · React 19 · Drizzle + Postgres · FastAPI model service

The request path does no fitting and no fetching. The scheduled job that touches data runs catchup, which can never call train or eval.
